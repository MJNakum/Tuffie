# Keyboard shortcuts

## Everywhere

| Key | Action |
|---|---|
| `?` | Open the help menu |

## Workspace pages

| Key | Action |
|---|---|
| `` Ctrl+` `` | Open or hide the terminal |

## Editors (files and policies)

| Key | Action |
|---|---|
| `Ctrl+S` / `Cmd+S` | Save |
| `Ctrl+F` / `Cmd+F` | Find |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo |
| `Tab` / `Shift+Tab` | Indent / outdent |
| `Ctrl+/` / `Cmd+/` | Comment the line |

## Terminal

| Key | Action |
|---|---|
| ↑ / ↓ | Command history |
| Tab | Complete |
| Ctrl+C | Stop the command, or clear the line |
| Ctrl+L | Clear the screen |
| Ctrl+A / Ctrl+E | Start / end of line |
| Ctrl+U / Ctrl+W | Delete the line / the last word |

## Guided tour

| Key | Action |
|---|---|
| → / Enter | Next step |
| ← | Previous step |
| Esc | Close the tour |
